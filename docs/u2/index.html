Conceito — Fetch API

Uma requisição em três linhas

A Fetch API é a forma moderna de fazer requisições HTTP no navegador. Ela retorna uma Promise — uma promessa de que algo vai chegar. Com async/await, escrevemos esse código assíncrono de forma linear e legível.

app.js // async → esta função pode "aguardar" respostas
async function carregarVeiculos() {

  // fetch envia GET e retorna uma Promise
  const resposta = await fetch('/api/v1/veiculos');

  // .json() lê o corpo e converte para objeto JS
  const veiculos = await resposta.json();

  // agora temos um array — usamos igual à etapa 1
  renderizar(veiculos);
}
💡 Por que async/await? Requisições de rede levam tempo. Se o código fosse síncrono, a página travaria esperando a resposta. Com async/await, o navegador continua responsivo enquanto aguarda.
Conceito — Tratamento de erros

O servidor pode não responder

Rede cai, servidor reinicia, URL errada. O código precisa lidar com isso de forma elegante, sem travar ou mostrar mensagens confusas ao usuário.

app.js async function carregarVeiculos() {
  try {
    const resposta = await fetch('/api/v1/veiculos');

    // verificar se o servidor respondeu com sucesso
    if (!resposta.ok) throw new Error(`HTTP ${resposta.status}`);

    const veiculos = await resposta.json();
    renderizar(veiculos);

  } catch (erro) {
    mostrarErro(erro.message);
  }
}
