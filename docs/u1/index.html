Neste momento, o navegador é o único ator. Ele baixa o HTML, renderiza o CSS e executa o JavaScript — tudo localmente, sem nenhuma chamada a um servidor.

Conceito — DOM

O navegador lê HTML e cria uma árvore

Quando o navegador carrega uma página, ele transforma o HTML em uma estrutura de objetos chamada DOM — Document Object Model. É essa árvore que o JavaScript manipula para mudar o que aparece na tela sem recarregar a página.

<table id="tabela-veiculos">
<thead>
<tr><th>Placa</th><th>Modelo</th></tr>
</thead>
<tbody id="tbody"> ← JavaScript escreve aqui
</tbody>
</table>
app.js // Acessar um elemento pelo id
const tbody = document.getElementById('tbody');

// Criar uma nova linha e inserir no DOM
const linha = document.createElement('tr');
linha.innerHTML = `<td>ABC-1234</td><td>Fiat Ducato</td>`;
tbody.appendChild(linha);
Conceito — Eventos

O usuário age, o JavaScript reage

Eventos são sinais que o navegador emite quando o usuário faz algo — clica, digita, passa o mouse. Com addEventListener, registramos uma função para ser executada quando o evento acontecer.

app.js // Quando o botão for clicado, chama a função
document.getElementById('btn-filtrar')
  .addEventListener('click', function() {
    filtrarVeiculos('ativo');
  });
