Conceito — REST

Um protocolo de intenções

REST (Representational State Transfer) é uma convenção — não uma tecnologia. Ela define como usar os verbos HTTP de forma semântica para criar APIs previsíveis e padronizadas.

Verbo URL O que faz SQL equivalente Status
GET /api/v1/veiculos Lista todos os veículos SELECT * 200
GET /api/v1/veiculos/:placa Busca um veículo SELECT WHERE 200 / 404
POST /api/v1/veiculos Cria um veículo INSERT INTO 201
PUT /api/v1/veiculos/:placa Atualiza um veículo UPDATE SET 200 / 404
DELETE /api/v1/veiculos/:placa Remove um veículo DELETE FROM 200 / 404

app.get('/api/v1/veiculos', ctrl.listar);

app.post('/api/v1/veiculos', ctrl.criar);
app.put('/api/v1/veiculos/:placa', ctrl.atualizar);
app.delete('/api/v1/veiculos/:placa', ctrl.remover);

app.listen(3000);
Conceito — Status Codes

O servidor não diz só "ok" ou "erro"

Status codes são números que comunicam o resultado de uma requisição de forma precisa. Uma boa API usa os códigos corretos — não retorna 200 para tudo.

200
OK
201
Created
204
No Content
400
Bad Request
401
Unauthorized
403
Forbidden
404
Not Found
500
Server Error
