← Voltar ao início Unidade 3 — Servidor Node.js Puro Node.js
Esta unidade é conceitual. Não há interface interativa aqui — o objetivo é entender como um servidor HTTP funciona por dentro, antes de usar qualquer framework. Compare o código desta unidade com o da U4 (Express) e veja o que muda.

O servidor sem framework

// servidor.js — Node.js puro, sem Express
const http = require('http');

const servidor = http.createServer((req, res) => {

  // precisamos verificar método E URL manualmente
  if (req.method === 'GET' && req.url === '/api/veiculos') {
    res.writeHead(200, { 'Content-Type': 'application/json' });
    res.end(JSON.stringify([{ placa: 'ABC-1234', modelo: 'Fiat Ducato' }]));

  } else if (req.method === 'POST' && req.url === '/api/veiculos') {
    // ler o body manualmente — trabalhoso
    let body = '';
    req.on('data', chunk => body += chunk);
    req.on('end', () => {
      const dados = JSON.parse(body);
      res.writeHead(201, { 'Content-Type': 'application/json' });
      res.end(JSON.stringify({ mensagem: 'Criado', dados }));
    });

  } else {
    res.writeHead(404);
    res.end(JSON.stringify({ erro: 'Rota não encontrada' }));
  }
});

servidor.listen(3000, () => console.log('Servidor na porta 3000'));
🚨 O problema: imagine adicionar rotas para veículos, motoristas, oficinas e manutenções — cada uma com GET, POST, PUT e DELETE. Esse if/else cresceria indefinidamente, seria difícil de ler e ainda mais difícil de manter.
✅ A solução está na U4: o Express resolve exatamente isso — organiza as rotas de forma declarativa, lida com o body automaticamente e separa as responsabilidades em arquivos diferentes (MVC).

O que este código ensina

// 1. Todo servidor HTTP recebe dois objetos: req (requisição) e res (resposta)
// 2. req.method → qual verbo HTTP foi usado (GET, POST, PUT, DELETE)
// 3. req.url → qual caminho foi acessado (/api/veiculos)
// 4. res.writeHead(status, headers) → define o código de resposta
// 5. res.end(body) → envia a resposta e encerra a conexão
// 6. O body do POST não chega de uma vez — precisamos "montar" com eventos
