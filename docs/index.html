Este é o Sistema de Gestão de Frota — construído ao longo das 8 unidades da disciplina DW2. Cada etapa abaixo representa uma camada técnica adicionada ao sistema. Se você acompanhou a disciplina, você é capaz de construir tudo isso.

8 etapas de construção HTML → CSS → JS → Node → Express → MySQL Front-end + Back-end + Banco de dados
A jornada de construção
01
A interface nasce
HTML semântico, CSS visual, JavaScript e manipulação do DOM. A tela de veículos ganha vida — estrutura, estilo e comportamento.
HTML CSS JavaScript DOM
→
02
A interface conversa
AJAX e Fetch API. A tela para de ter dados fixos e começa a buscar informações de um servidor, atualizando sem recarregar a página.
Fetch API AJAX Async/Await JSON
→
03
O servidor responde
Node.js puro. Criamos o servidor do zero — sem framework — para entender o que acontece por baixo de cada requisição HTTP.
Node.js HTTP req / res
→
04
A API toma forma
REST com Express. Rotas declarativas, verbos HTTP corretos, status codes semânticos. O servidor vira uma API profissional.
Express REST GET / POST / PUT / DELETE
→
05
O código se organiza
Front Controller e MVC. O projeto cresce sem virar caos — cada arquivo tem uma responsabilidade clara e o código se torna legível.
MVC Front Controller Arquitetura
→
06
Quem pode entrar?
Sessões, autenticação e controle de acesso. O sistema aprende a reconhecer quem é quem e proteger o que precisa ser protegido.
Sessão Autenticação JWT Autorização
→
07
Os dados persistem
Integração com MySQL via mysql2. Os veículos, motoristas e oficinas deixam de existir só na memória e passam a viver no banco de dados.
MySQL mysql2 frota_db CRUD real
→
08
O sistema completo
Todas as camadas unidas. O projeto final — uma aplicação web real, com front-end, API REST, autenticação e banco de dados funcionando.
Front-end Back-end Banco Segurança
→
