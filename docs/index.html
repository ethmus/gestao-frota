🚛 Sistema de Gestão de Frota

Projeto demonstrativo da disciplina Desenvolvimento Web 2

IFCE — Informática para Internet (EAD)
Este projeto foi construído unidade por unidade, seguindo exatamente o conteúdo da disciplina DW2. Se você acompanhou cada aula e realizou as atividades, você é capaz de construir este sistema do zero. Explore cada unidade abaixo para ver o resultado de cada etapa.

Unidades do Projeto

Unidade 1

Interface Estática

Tela de listagem de veículos construída com HTML e CSS puro. Sem lógica, sem dados reais — só estrutura e visual.

HTML CSS
Unidade 2

Consumindo uma API

A mesma tela agora busca dados reais com Fetch API. Os veículos vêm do servidor — a interface apenas exibe.

JavaScript Fetch API JSON
Unidade 3

Servidor Node.js Puro

Como o servidor funciona por dentro — sem framework, respondendo requisições HTTP manualmente.

Node.js HTTP
Unidade 4

API REST com Express

O servidor refatorado com Express. Rotas limpas, verbos HTTP corretos, status codes adequados.

Express REST CRUD
Unidade 5

Integração com Banco de Dados

Sistema completo: front-end → Fetch → API REST → mysql2 → frota_db. Dados reais, persistência real.

MySQL mysql2 MVC
