O que foi construído

Sete camadas, um sistema

01 Interface — HTML + CSS + JavaScript + DOM Front-end
02 Comunicação — Fetch API + AJAX + Async/Await Client ↔ Server
03 Servidor — Node.js + módulo HTTP Back-end
04 API REST — Express + verbos HTTP + status codes API Layer
05 Arquitetura — MVC + Front Controller Organização
06 Segurança — Sessão + JWT + Autenticação + bcrypt Auth
07 Persistência — MySQL + mysql2 + frota_db Banco de dados
