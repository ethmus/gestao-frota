O problema que MVC resolve

Um arquivo que faz tudo não é manutenível

app.js — sem MVC (problema) // rotas, lógica e dados tudo no mesmo arquivo
app.get('/api/v1/veiculos', (req, res) => {
  // validação aqui
  // busca no banco aqui
  // formatação aqui
  // resposta aqui
  // ... 50 linhas de lógica ...
});

app.post('/api/v1/veiculos', (req, res) => {
  // mais 50 linhas...
});
⚠️ Com 4 entidades × 5 rotas = 20 handlers num arquivo só. Cada handler com 30-50 linhas = um arquivo de 600-1000 linhas. Inviável de manter.
Conceito — MVC

Três responsabilidades, três lugares

M

Acessa o banco de dados. Contém as queries SQL. Não sabe nada sobre HTTP.
veiculoModel.js
motoristaModel.js

Recebe req, chama o Model, monta a resposta. É o mediador.
veiculoController.js
motoristaController.js
oficinaController.js
V
View
Em APIs REST, a View é o JSON retornado. No front-end separado, é o HTML/CSS/JS.

← front-end consome
Conceito — Front Controller

Uma porta de entrada única

O Front Controller é o padrão onde todas as requisições passam por um único ponto de entrada — o app.js. Ele não resolve nada diretamente: apenas distribui o trabalho para os roteadores corretos.

app.js — Front Controller const express = require('express');
const app = express();
app.use(express.json());

// delega para os roteadores — não resolve nada aqui
app.use('/api/v1/veiculos', require('./routes/veiculoRoutes'));
app.use('/api/v1/motoristas', require('./routes/motoristaRoutes'));
app.use('/api/v1/oficinas', require('./routes/oficinaRoutes'));

app.listen(3000);

O fluxo de uma requisição

O que acontece quando GET /api/v1/veiculos chega

1
app.js recebe a requisição
Front Controller identifica o prefixo /api/v1/veiculos e passa para veiculoRoutes
2
veiculoRoutes.js identifica a rota
router.get('/') → chama veiculoController.listar
3
veiculoController.js processa
Chama veiculoModel.listar(), aguarda o resultado
4
veiculoModel.js consulta o banco
db.execute('SELECT * FROM VEICULO') → retorna array
5
Controller responde
res.json(veiculos) → 200 OK + JSON
✅ O que aprendemos: padrão MVC, Front Controller, separação de responsabilidades, require/module.exports, Router do Express, e por que arquitetura importa quando o projeto cresce.
